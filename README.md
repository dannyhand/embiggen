# embiggen
Turn your phone into a billboard

emBiggen was once an android app that would make bigger whatever text you entered. I recreated it in html and javascript. Features include a color chooser for both background and text, and the option to save your text to recall later.

Try it out at https://dannyhand.us/embiggen/

It also works as a colorful flashlight to help your friends find you in a crowd, if you set background and text both to a bright color.
